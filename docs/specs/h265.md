# H.265

Tier 1 throughout. All cites are ITU-T H.265 V10 (07/2024). Anchors L4.1
and L6.2 cross-checked against an independent second source.

## Profiles (A.3)

idc 1 Main: 8-bit 4:2:0 (A.3.2). idc 2 Main 10: 8-10-bit 4:2:0 (A.3.3).
idc 3 Main Still Picture: 8-bit 4:2:0, one picture (A.3.4). idc 4 range
extensions per Table A.1 (A.3.5). idc 5 high-throughput profiles (A.3.6).
idc 9 screen-content profiles with IBC and palette (A.3.7). idc 11
high-throughput screen-content (A.3.8). Scalable and multiview names live
in Annex F/G/H; scalable range extensions use idc 10 (H.11), 3D Main
uses idc 8. Full Annex H.11 constraint rows are unmapped.

## Tiers (A.4.1)

Tier flag 0 is Main, 1 is High. High tier exists only at L4 and up.
level_idc is 30x the level number.

## NAL (Table 7-1, 7.4.2.2)

Types 0-63. IRAP types: 16 BLA with LP, 17 BLA with RADL, 18 BLA with no
leading, 19 IDR with RADL, 20 IDR with no leading, 21 CRA; 22-23
reserved. Leading pictures: types 6-7 RADL, 8-9 RASL. Quirks: IDR never
carries RASL; no-leading variants carry no leading pictures; CRA carries
a non-empty reference set with RASL/RADL and random-access entry drops
RASL; BLA behaves as IDR with a non-empty set and always starts a new
coded video sequence. The first access unit is always IRAP.

## Reference sets (8.3.2)

Absolute reference description over five Poc lists. IDR empties all
lists. IRAP with NoRaslOutputFlag set flushes DPB references.

## HRD (C, E.3.2-3)

Type I covers VCL plus filler only, Type II adds the rest (C.1). HRD
parameters ride in VPS/SPS; SchedSelIdx arrives via buffering period,
picture timing, and decoding-unit SEI. CPB covers arrival plus nominal
and actual removal at access-unit and decoding-unit granularity (C.2);
DPB covers output, bumping, and latency (C.3).
