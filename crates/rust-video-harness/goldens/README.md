# Goldens

One file per case: `<case>.sha256`, one lowercase hex SHA-256 per line in
frame output order. Blank lines and `#` comments are skipped. The hash covers
raw decoded frame bytes at the probed pixel format. Generated by
`just goldens` (see `docs/testing/goldens.md`); the generator preserves
non-`.sha256` files in this directory across regens.
