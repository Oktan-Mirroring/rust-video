# Goldens

One file per matrix line: `<codec>/<line>.sha256`, generated by `just
goldens` (see `docs/testing/goldens.md`). Each file is a v1 header plus
zero or more lowercase hex SHA-256 hashes, one per decoded frame in
output order. The hash covers raw decoded frame bytes at the probed
pixel format.

Header lines:

- `# vector:` corpus path of the vector (forward slashes).
- `# expect:` `match` (tiers decode byte-exact), `either <reason>`
  (tiers decode byte-exact or decline cleanly), or `decline <reason>`
  (tiers must return `Err`; the file carries zero hashes).
- `# probe:`, `# frames:`, `# recipe:` describe the oracle run.

Vectors are rebuilt by `just vectors` (one pinned fetch) plus `just
goldens --synth` (canonical clips, encoder recipes, byte crafts) and
are never committed. The generator preserves non-`.sha256` files in
this directory across regens.
